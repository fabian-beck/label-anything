# 0004 — Bundled font and "simple shaping"

* Status: accepted
* Date: 2026-10-16

## Context
Text widths must be identical (±0.01 px) between Rust and TS in simple-shaping mode
for the bundled font. Bundle size matters for the browser and WASM packages.

## Decision
* Font: **Noto Sans 2.015** Regular and Bold (SIL OFL 1.1), subset to Latin, Greek and
  Cyrillic (+ punctuation incl. `…`) with fonttools (`tools/fonts/subset.py`), hinting
  removed. Source: the static instances shipped in `@expo-google-fonts/noto-sans@0.4.2`.
* Two files per weight: with outlines (≈ 243 KB, for rendering) and **metrics-only**
  (outlines removed, ≈ 80 KB, 28 KB gzipped). Only the metrics-only files are embedded
  (Rust `include_bytes!`, TS base64 module generated by `tools/codegen.mjs`). Both files
  share identical cmap/hmtx/hhea/OS2/GDEF/GSUB/GPOS tables.
* **Simple shaping** (spec §5.2): cmap → hmtx advances + GPOS PairPos (type 2 and
  extension type 9) of the `kern` feature, lookups applied in index order, IgnoreMarks via
  GDEF. Integer font-unit sums, one scale at the end ⇒ bit-identical widths.
* **Full shaping** (Rust only): rustybuzz, used for complex scripts (`text.shaping`).
  TS documents the limitation and accepts a `measure` callback (e.g. canvas
  `measureText`) or `harfbuzzjs` when installed.

## Consequences
Latin/Greek/Cyrillic labels measure identically everywhere. Other scripts need user
fonts; in TS they are measured with simple shaping unless a `measure` hook is given.
