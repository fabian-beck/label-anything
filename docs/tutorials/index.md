# Tutorials

Each tutorial solves one task. The code is included from
[`examples/tutorials/`](gh:examples/tutorials), and CI runs every program there and checks
what the tutorial says about its result (`examples/tutorials/run.py`), so what you read
is what runs. The data — a scatter chart as PNG and SVG, its outliers, a map, a skyline
photo — is generated by `examples/tutorials/data/make_data.py`.

| Tutorial | You learn | Code |
|---|---|---|
| [Label your outliers in 5 lines](outliers.md) | the core loop, in Python, JavaScript, Java, C, Go and the CLI | all |
| [Labels over an SVG background](svg-background.md) | CSS selectors to obstacle classes, marks from SVG elements, warnings | JSON, Python |
| [Raster backgrounds](raster-backgrounds.md) | the ink, alpha, cost, classmap and saliency modes | JSON, Python |
| [Leaders and leader styles](leaders.md) | distant labels, the five leader styles, boundary labels | JSON, Python |
| [Priority and omission](priority.md) | what is dropped when not everything fits, and why | JSON, Python |
| [Shapes](shapes.md) | true mark shapes, internal labels, icons, area anchors | JSON, Python |
| [Interactive maps and stability](interactive-maps.md) | warm starts, nesting, Leaflet and MapLibre | Python, JavaScript |
| [Node-link diagrams](node-link.md) | nodes as items, edges as obstacles, Cytoscape and sigma | JSON, Python, JavaScript |

To run them yourself:

```sh
python3 examples/tutorials/run.py cli --cli rust/target/release/label-anything
python3 examples/tutorials/run.py python          # with label_anything installed
python3 examples/tutorials/run.py js              # after npm ci && npm run build
```
