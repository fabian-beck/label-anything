# Label Anything playground

The engine running in the browser on six scenes — a world map, a network, a scatterplot,
a line chart, a swarm of moving points and annotated photographs — with every option of
the problem format in a panel. Published with the documentation site at
<https://fabian-beck.github.io/label-anything/playground/>; the decisions behind it are in
[ADR 0032](../../../docs/adr/0032-playground.md).

`explain.html` (*How it works*) steps through a real solve: the TypeScript engine records
its decisions while it solves (`placeTraced`), and the page replays them — candidates and
their costs, the greedy pass, the ladder, every local-search move, the repairs and the
verification — on four small scenes whose marks can be dragged ([ADR
0046](../../../docs/adr/0046-solve-traces-and-the-explainer.md)).

## Run it locally

```sh
npm ci && npm run build                          # the packages it bundles (repository root)
npm run build:wasm -w @label-anything/wasm        # optional: the WebAssembly engine
npm run build -w @label-anything/playground       # dist/
node ts/packages/playground/test/server.mjs 8000  # http://127.0.0.1:8000/ (explainer: /explain.html)
```

`npm run dev -w @label-anything/playground` rebuilds on change and serves dist/ on port
8000. Without the WebAssembly build the playground solves with the TypeScript engine only.

The build also makes `dist/hero.js`, the live header of the documentation's home page
(`docs/_overrides/home.html`): the logo, with the name on its label, among random things
(a rubber duck, coffee, the moon, …), solved with `engine-ts.js`. The home page loads it from the playground's directory
([ADR 0049](../../../docs/adr/0049-home-page-header-labeled-live.md)).

## Tests

* `npx vitest run ts/packages/playground` — every option control writes a problem the
  engine's validator accepts; the merge, path and share-link helpers; the explainer's
  view of a trace agrees with the solver (the free candidates it shows at each greedy pick
  are the solver's count, random access to any step equals the replay) for each scene
  under several option variants.
* `npm run test:browser -w @label-anything/playground` — builds, then checks in Chromium
  that every scene solves without overlaps, that WebAssembly and TypeScript give identical
  placements, that options and share links take effect, that labels keep off the controls
  on the drawing and that clicking the picture adds a label; that every scene of the
  explainer solves, matches the WebAssembly engine, and can be stepped, dragged and
  solved again; and that the home page's header keeps the name where the static logo has
  it, places every label off its text, stays still until someone interacts, and follows
  drags, clicks and shuffles (`test/hero.pw.mjs`).
  CI runs both (job `wasm`) and uploads dist/ as the artifact the Pages workflow
  publishes.

## Layout

| Path | |
|---|---|
| `src/app.ts` | state, problem building, the solve loop (cold, warm and settle solves), drawing, pointer handling, share links |
| `src/engines.ts`, `src/worker-*.ts` | the WebAssembly and TypeScript engines in Web Workers (`createWorkerEngine` of `@label-anything/extras`) |
| `src/controls.ts`, `src/ui/` | the option controls (one problem field each) and the Options, Inspect and Code tabs |
| `src/render.ts` | canvas drawing of labels, leaders and the diagnostic overlays |
| `src/scenes/` | one module per scene: data, items, obstacles, simulation, drawing |
| `explain.html`, `explain.css`, `src/explain/` | the explainer: the traced engine's worker, its scenes, the trace's phases and replay (`model.ts`), the explanations (`narrate.ts`), drawing a step (`draw.ts`), the timeline, the page (`app.ts`) |
| `src/hero.ts` | the live header of the documentation's home page (`dist/hero.js`) |
| `data/` | derived data, committed (below); `data/modules.json` is generated by `build.mjs` |
| `tools/` | the scripts that derive `data/world.json` and `data/pictures/` |

## Data

| File | Source | License |
|---|---|---|
| `data/world.json` | Natural Earth 1:50m admin 0 countries, simplified (`tools/make_world.py`) | public domain |
| `data/pictures/*.jpg` | scikit-image sample images: astronaut (NASA), rocket (SpaceX), retina (M. Häggström) (`tools/make_pictures.py`) | public domain, CC0 |
| `data/pictures/pictures.json` | annotation polygons of `bench/scenarios/08-illustration/polygons.json`, scaled | CC0 1.0 |
| `data/modules.json` (generated) | the import graph of the TypeScript packages of this repository | MIT |

Both scripts read the pinned, checksummed sources of the benchmark
(`bench/common/sources.py`): `bench/.venv/bin/python ts/packages/playground/tools/make_world.py`.
The fonts are the bundled Noto Sans (SIL OFL 1.1); dist/THIRD-PARTY-NOTICES.txt lists the
licenses of the bundled npm packages.
